# Gustavo Portela — Cinematic Portfolio

Portfólio fullstack cinematográfico com Next.js, React Three Fiber, GSAP e Lenis.

## Stack

- Next.js (App Router) + React 19 + TypeScript
- Tailwind CSS 4
- React Three Fiber / Three.js / Drei / Postprocessing
- Framer Motion + GSAP ScrollTrigger + Lenis
- React Hook Form + Zod

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Atalhos

- `Ctrl/Cmd + K` — Command palette

## Build

```bash
npm run build
npm start
```

## Conteúdo

Atualize `src/lib/constants.ts` para projetos, experiência e contatos.
